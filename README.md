- **公開URL (GitHub Pages)**: [https://mukkii-game.github.io/GeminiGuidance/](https://mukkii-game.github.io/GeminiGuidance/)

## 🕹️ 操作方法

### 📱 スマートフォン（指1本で快適プレイ）
- **移動 & スイング**: 画面どこでも1本指ドラッグで自機が滑らかに追従（指で隠れないエルゴノミックオフセット設計）。
- **地上ブラスター**: 自機前方の照準レティクル内に地上ターゲットが入ると自動投下！片手で旋回スイングに100%集中できます。

### 💻 PC（マウス & キーボード）
- **マウス**: マウス追従移動 ＋ 左クリック（または地上照準で自動投下）。
- **キーボード**: `WASD` または `[↑][↓][←][→]` で移動、`[Space]` / `[Z]` / `[J]` でブラスター投下。
- **CRT表示切替**: `[C]` キー または 画面下部ボタン
- **サウンド切替**: `[M]` キー または 画面下部ボタン
